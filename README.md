# 词屿：英日双语词典与复习工具

## 现在有什么
- 英文查词：Free Dictionary API，按可用结果展示英语释义、词性、发音、例句。
- 日文查词：尝试连接 Jisho 的公开接口；如果浏览器跨域限制阻止请求，会给出在线词典入口。
- 收藏词条、编辑、删除、标签、手动添加。
- 间隔重复复习：忘了 / 模糊 / 记住了。
- 本地保存、JSON 导出与导入备份。
- PWA 基础文件：支持通过 HTTPS 托管后添加到手机主屏幕。

## 重要说明
这是可运行的第一版原型。词源、词根和完整英日互译尚未自动覆盖所有词条；可在编辑页面手动补充。各公开词典接口的可用性、跨域策略和服务条款可能变化。
词库保存在当前浏览器的 localStorage 中。请定期导出 JSON 备份。不要清除浏览器网站数据，除非已备份。

## 手机上怎么打开
1. 把本文件夹中的文件放到支持 HTTPS 的静态网站托管服务，例如 GitHub Pages。
2. 打开发布后的 HTTPS 地址。
3. iPhone Safari：分享按钮 → 添加到主屏幕。
   Android Chrome：浏览器菜单 → 安装应用 / 添加到主屏幕。
4. 安装后可以离线打开应用外壳和复习已保存的词条；在线词典查询仍需要网络。

## 电脑本地预览
建议用 VS Code 的 Live Server 扩展启动本文件夹。直接双击 HTML 也能打开基础界面，但浏览器对 PWA、Service Worker 和部分跨域请求有限制。

## 免费使用的边界
此项目不需要上架，也不需要付费开发者账号。在线查询取决于第三方词典服务；本项目不提供任何付费 API 密钥，也不保证第三方服务永远免费或始终可访问。
